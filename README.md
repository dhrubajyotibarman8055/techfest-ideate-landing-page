# Techfest Ideate Landing Page

A modern, interactive landing page concept for **Techfest**, designed to deliver an engaging digital experience through creative visuals, animations, and responsive UI.

## Overview

This project is a frontend website concept created for the Techfest Ideate Landing Page task. It focuses on modern web design, visual storytelling, smooth interactions, and responsive layouts.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- CSS Animations

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/dhrubajyotibarman8055/techfest-ideate-landing-page.git
```

Navigate to the project directory:

```bash
cd techfest-ideate-landing-page
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Build for Production

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## Deployment

This project is configured for deployment using **GitHub Pages** through GitHub Actions.
